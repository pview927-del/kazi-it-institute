ওয়েবসাইটটি মোবাইল অ্যাপের মতো ব্যবহার করুন

Home Screen-এ যোগ করে এক ট্যাপে KAZI IT AND INSTITUTE খুলুন। নোটিশের Push Notification-ও চালু করতে পারবেন।

＋

Home Screen-এ যোগ করুন

ওয়েবসাইটটি অ্যাপের মতো আলাদা আইকন থেকে খুলতে পারবেন। Android Chrome-এ Install অপশন দেখালে সেটি ব্যবহার করুন।

ওয়েবসাইট খুলুন

iPhone হলে Safari → Share → Add to Home Screen ব্যবহার করুন।

♧

নোটিশ নোটিফিকেশন চালু করুন

Admin নতুন নোটিশ প্রকাশ করলে এই ডিভাইসে Push Notification পাওয়ার জন্য অনুমতি দিন।

অনুমতি চাইলে Allow চাপুন। Browser notification বন্ধ থাকলে সেটিংসেও চালু থাকতে হবে।

যদি Install বাটনে কাজ না হয়

  1. Chrome-এ এই পেজটি খুলুন এবং HTTPS সংযোগ নিশ্চিত করুন।
  2. Chrome-এর ⋮ মেনু খুলুন।
  3. Install app অথবা Add to Home screen চাপুন।
  4. Home Screen-এ KAZI IT আইকন থেকে ওয়েবসাইট খুলুন।

Push notification কাজ করতে সাইটের অনুমতির পাশাপাশি সার্ভার-side Push service configure থাকতে হয়।
