২. Android / Chrome-এ ইনস্টল

  1. Chrome ব্রাউজারে Admin App পেজ খুলুন।
  2. উপরের তিন ডট মেনুতে চাপ দিন।
  3. Install app অথবা Add to Home screen বেছে নিন।
  4. নিশ্চিত করুন। Home Screen-এ KAZI Admin আইকন তৈরি হবে।
  5. আইকন থেকে অ্যাপ খুলে Admin Panel-এ লগইন করুন।

৩. একবার লগইন সম্পর্কে

সেশন চালু থাকলে একই ফোন/ব্রাউজারে সাধারণত বারবার লগইন করতে হবে না। তবে ব্রাউজারের ডেটা মুছে গেলে, সেশন মেয়াদ শেষ হলে বা নিরাপত্তার কারণে Supabase সেশন বাতিল হলে আবার লগইন করতে হতে পারে।

নিরাপত্তা: শুধু নিজের ফোনে ইনস্টল করুন, ফোনের স্ক্রিন লক রাখুন এবং অন্যের ফোনে লগইন করে রাখবেন না।

নোট: অ্যাপ ইনস্টল থাকলেই ফোনের ব্যাকগ্রাউন্ডে সবসময় চালু থাকবে না। ওয়েবসাইট/সার্ভার অনলাইনে থাকবে, কিন্তু অ্যাপ নিজে থেকে সবসময় চলবে না।
