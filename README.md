# KAZI IT AND INSTITUTE — Website

A responsive, single-page Bengali website for an offline computer training institute.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript in one file).

## Before publishing
1. Open `index.html` and replace `8801XXXXXXXXX` in `WHATSAPP_NUMBER` with the institute's WhatsApp number in international format, digits only (Bangladesh: start with 880; do not include +).
2. Replace the example contact phone/address/class schedule with the institute's real details.
3. Review the example course list and update it to match the courses actually offered.

## Enable free GitHub Pages hosting
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to publish. The expected URL is https://pview927-del.github.io/kazi-it-institute/ (only use it once GitHub confirms deployment).

## Important limitations
- This is a static informational website.
- The enquiry form prepares a WhatsApp message; it does not save submissions to a database.
- Student login, OTP, admin dashboard, course management, online payments and a database are not included.
- Google Fonts require an internet connection.
